# UkayLive Demo

Mobile-first demo storefront and seller workspace for TikTok LIVE ukay-ukay sellers.

## Features
- Responsive catalog with item codes, prices, sizes, condition, and availability
- Search plus category and status filters
- Claim form using a TikTok username; seller confirmation is required
- Seller view: add items, cycle status (Available → Claimed → Sold), and remove inventory
- Browser localStorage persistence for demo data
- No backend, payment processing, or TikTok Shop integration

## Run
Open `index.html` in a browser, or deploy as a static site on Vercel/GitHub Pages.

## Demo notes
Seed products and image URLs are illustrative. Replace them with the seller's real inventory/photos.
Claims are stored only in the current browser. For production, add authentication and server-side database authorization.
